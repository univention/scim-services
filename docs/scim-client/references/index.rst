.. _scim-client-references:

**********
References
**********

This chapter provides reference information for the *SCIM Client*.
It covers supported schemas and attribute mappings, implementation limitations,
and Helm Chart values.

:ref:`scim-client-schemas`
   SCIM schemas define the attributes of users and user groups.
   This reference lists the schemas and attribute mappings
   that the *SCIM Client* supports.

:ref:`scim-client-limitations`
   The *SCIM Client* has limitations that affect integration with a *SCIM target*.
   This reference describes restrictions on data synchronization
   and attribute mapping.

:ref:`scim-client-reference-values`
   The *SCIM Client* Helm Chart provides values to configure the deployment.
   This reference lists the available values and their defaults.
